# ArcticClonePersistence
Repository for R code and raw data associated with the manuscript "Carcass-mediated persistence extends transmission opportunity for an emerging Arctic pathogen"

# Prerequisites
R and RStudio are necessary for running the R code. The following R packages are required: "beepr","broom.mixed","DHARMa","doParallel","dplyr","DT","forcats","foreach","ggeffects","ggplot2","glmmLasso","glmmTMB","hglm","icenreg","Icens","interval","janitor","knitr","lme4","lmerTest","patchwork","progress","purrr","raster","readr","readxl","rmarkdown","scales","sf","stats","stringr","survival","terra","tibble","tidyr","tidyverse","tinytex","vegan","viridis"
